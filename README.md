# Golc

---

An simple calculator made in **Go**,
And is also my first project in Go!

## Installation

---

```
go install github.com/SlibProg/golc@latest
```

## Usage

---

For now, you can only use addition, subtraction, multiplication and division (+ - / \*)

```
golc 6 \* 4 + 3 +3 +3
```
